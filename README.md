# Breakout 打砖块游戏

## 项目简介
这是一个基于 C++ 与 Raylib 开发的经典打砖块游戏项目，也是本学期 C++ 课程的综合实践作品。项目完整实现了游戏核心玩法、道具系统、存档读档、关卡解锁等功能，旨在通过实战项目巩固 C++ 基础语法与面向对象编程思想。

## 编译运行步骤
### 1. 环境准备
- 操作系统：Linux / macOS / Windows
- 依赖工具：CMake、Make、Raylib 库
- 编译环境：支持 C++17 的编译器
### 2. 构建与编译
```bash
# 克隆仓库
git clone https://github.com/leiyin326/break_out.git
cd break_out

# 创建构建目录并编译
mkdir build && cd build
cmake ..
make 
3. 运行游戏
bash
运行
# 在 build 目录下执行
./breakout_week4
🎮 操作说明
表格
按键	    功能

y           还原到上局结束时进度
n           重开

核心玩法：小球与砖块、球拍的碰撞检测，砖块破坏与分数统计

##  项目结构

break_out/
├── build/                  # 编译产物目录（CMake构建生成，存放可执行文件、中间目标文件）
├── fonts/                  # 字体资源目录，存放游戏使用的字体文件
├── levels/                 # 关卡配置目录，存放JSON格式的关卡数据文件
├── sounds/                  # 音频资源目录，存放音效文件（砖块破碎、道具、胜利等）
├── src/                    # 源代码目录
│   ├── Ball.cpp/.h         # 小球类：实现小球的移动、碰撞、速度控制与生命周期管理
│   ├── Brick.cpp/.h        # 砖块类：定义砖块的位置、颜色、状态（是否激活/金色）与碰撞逻辑
│   ├── config.json         # 游戏配置文件：窗口大小、颜色、球/球拍参数、游戏规则等
│   ├── Game.cpp/.h         # 游戏核心类：状态管理、主循环、输入处理、碰撞检测、存档读档
│   ├── json.hpp            # JSON解析库头文件，用于读取配置与存档文件
│   ├── main.cpp            # 程序入口：初始化游戏并启动主循环
│   ├── Paddle.cpp/.h       # 球拍类：控制球拍移动、宽度变化、与小球的碰撞
│   ├── Particle.cpp/.h     # 粒子类：实现砖块破碎、道具光环等特效
│   ├── ParticlePool.h      # 粒子池：优化粒子对象创建/销毁，提升性能
│   ├── PowerUp.cpp/.h      # 道具系统：定义道具类型（加宽球拍/多球/额外生命）、效果与生命周期
│   └── tests.cpp           # 单元测试文件（用于功能验证）
├── .gitignore              # Git忽略文件，指定不需要提交到仓库的文件/目录
├── CMakeLists.txt          # CMake构建配置文件，定义编译规则、源文件与依赖
└── README.md               # 项目说明文档：简介、编译运行、操作说明、功能列表
